# 授業時間割マネージャー（端末内保存版）

公開URL：https://learning-apps-jp.github.io/timetable-app/

Googleの設定やログインは不要です。授業・基本時間割・記録・候補マスタ・採番・移動と交換・CSV出力・JSONバックアップと復元に対応します。

データは利用中の端末・ブラウザーのlocalStorageに保存します。別端末には自動同期しません。設定からJSONバックアップを定期的に保存し、別端末ではそのJSONを読み込んでください。ブラウザーの保存データ削除やプライベートモード終了でデータが消える場合があります。

元のGoogle Apps Script版からエクスポートしたバージョン1のJSONも読み込めます。共有端末では個人専用のブラウザープロファイルを利用してください。
